§ 02 — The Six Components

Every network — from MNIST to GPT — is built from these six elements.

Three describe structure, three describe how it learns. Master the vocabulary and the rest becomes legible.

№ 01 Structure

Layers

Stacked groups of neurons that process data sequentially. Three types: input receives data, hidden transforms it, output produces predictions. Depth = number of hidden layers.

In the Playground: + / − buttons above the network add or remove hidden layers.

№ 02 Computation

Neurons

The basic computational unit. Each neuron multiplies inputs by weights, sums them with a bias, and runs the result through an activation function. Thousands together produce intelligence.

Formula: output = activation(w₁·x₁ + … + bias)

№ 03 Weights

Weights

Numerical values that determine how strongly each input influences a neuron's output. Training is the process of adjusting weights. The network's knowledge lives in its weights.

In the Playground: Line thickness = magnitude. Blue = positive, orange = negative.

№ 04 Activation

Activation Functions

Mathematical functions that introduce non-linearity, letting networks learn curves rather than just straight lines. Without them, depth is meaningless. Common: ReLU, Tanh, Sigmoid.

In the Playground: "Activation" dropdown in the top bar.

№ 05 Loss

Loss Functions

A measurement of how wrong the network's predictions currently are. Lower = better. Common: Mean Squared Error (regression), Cross-Entropy (classification). The network's report card.

In the Playground: "Training loss" and "Test loss" in the top-right.

№ 06 Optimizer

Optimization Algorithms

Procedures that adjust weights to reduce the loss. The classic: gradient descent — calculate direction, take a step, repeat. Modern variants: Adam, SGD, RMSprop.

In the Playground: "Learning rate" dropdown controls step size.

§ 03 — Hands-on Evidence

Three controlled experiments, three unmistakable lessons.

Each experiment changes one variable and holds everything else constant. The differences are dramatic.

Experiment № 01

Capacity — why network size matters.

Structure Computation
Dataset Spiral · Activation Tanh
Layers 2 hidden (8 + 6 neurons)
Learning Rate 0.03

I started with 2 hidden layers (4 + 2 neurons) on the spiral dataset. After training for over 8,000 epochs, the loss plateaued at 0.24 — far from solving the problem. The 2-neuron second layer was a bottleneck: even when the first layer learned useful features, the network couldn't carry enough of them forward. After widening to 8 + 6 neurons, the loss dropped to 0.034 in just 1,342 epochs — over 6× faster — and the decision boundary cleanly wrapped both spiral arms.

Takeaway Network capacity, not training time, was the limiting factor. Adding neurons let the network detect more features in parallel, giving the second layer enough information to compose them into the spiral shape. This is compositional learning in action.
Experiment № 02

Activation — why non-linearity is everything.

Activation
Same as № 01, with one change:
Linear activation instead of Tanh.

Switching from Tanh to Linear caused catastrophic failure. The decision boundary collapsed from a curling spiral into a simple diagonal gradient — essentially a single tilted line. The reason: a linear function of a linear function is still linear. Stacking linear activations collapses the entire network into a single linear equation. A 14-neuron, 2-layer linear network has the same expressive power as a single neuron with no hidden layers.

Takeaway Non-linearity is not optional. Activation functions are what give neural networks their power to learn curved patterns. Without them, depth becomes meaningless — and a network can only ever draw straight lines.
Experiment № 03

Learning Rate — the Goldilocks problem.

The learning rate controls how big each weight adjustment is. I tested three values on the same simple dataset to find the Goldilocks zone — and discovered that bigger steps aren't always faster.

Takeaway Bigger steps aren't always faster. Too high causes chaos; too low causes slow training. Surprisingly, the smallest learning rate converged fastest — because the optimizer settled cleanly without overshooting. Hyperparameter tuning is one of the most important parts of training.

§ 05 — Summary

Four key insights from the Playground.

What visualizing neural networks reveals about how AI actually works.

№ 01

Structure is simple.

A neural network is just neurons organized into layers, connected by weights — repeated as needed.

№ 02

Learning is weight adjustment.

The mystery of "how AI learns" reduces to: measure error, nudge weights, repeat.

№ 03

Non-linearity is everything.

Without activation functions, depth is meaningless. The biggest single insight from the Playground.

№ 04

Hyperparameters matter.

Even a perfect architecture is ruined by the wrong learning rate. Tuning is half the work.
